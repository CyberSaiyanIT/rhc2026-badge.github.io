# ROMHACK Camp 2026 badge: getting started

A static site (Astro + Tailwind CSS v4) with a five-step setup wizard for the Romhack Camp 2026 badge

## Develop

```sh
npm install
npm run dev      # http://localhost:4321
npm run build    # output in dist/
```

Node 22.12 or newer is required.

## Flasher notes

- It needs Web Serial: desktop Chrome, Edge or another Chromium browser, on HTTPS (GitHub Pages) or localhost.

## Stack

Astro, Tailwind CSS v4 (`@tailwindcss/vite`), `@fontsource/lato`, `esptool-js`.
